# 🏋️ GymBros – E-commerce de Produtos de Academia

**GymBros Supplements** é um sistema de e-commerce voltado para a venda de produtos de academia, como suplementos, equipamentos e acessórios. O sistema foi desenvolvido com foco em escalabilidade, organização de perfis e usabilidade para os diferentes usuários da plataforma.

---

## 🚀 Funcionalidades Principais

### 📦 Área Comum (Todos os Perfis)
- 🛒 Carrinho de compras  
- 💳 Checkout
- 💳 Módulo de pagamento  
- 🔐 Login e cadastro
- 🚚 Cálculo de frete
- 🦾 Recursos de acessibilidade

### 🔧 Área Administrativa
- 🧑‍💼 **Administrador**  
  - CRUD de produtos
  - Banco de imagens
  - Gerenciamento de estoque
  - Gerenciamento de promocoes
  - Gerenciamento de categorias
  - Gerenciamento de usuarios   

- 📤 **Exportação de Dados**  
  - Exportar para CSV, PDF e Excel  
- 📦 **Operador de Pedidos**  
  - Gerenciamento completo dos pedidos realizados  

---

## 👥 Perfis de Usuário

- **Administrador**  
- **Cliente**

---

## 🧰 Tecnologias Utilizadas

- ⚙️ **.NET 9 / ASP.NET Core MVC** – Backend e estrutura web  
- 🧱 **Entity Framework Core** – ORM para acesso a dados  
- 💾 **SQL Server** – Banco de dados relacional  
- 💡 **DDD e Clean Architecture** – Organização modular por responsabilidades  
- 🎨 **Razor Views (.cshtml)** – Renderização do frontend com HTML dinâmico  
- 🌐 **Bootstrap / CSS** – Estilização da interface
